    Lançamentos do mês

      Como usar

      Use o extrato e a fatura para registrar cada entrada e cada compra. Se já lançou as compras do cartão, pule o pagamento da fatura para evitar contar os mesmos gastos duas vezes.

      Ignore transferências entre suas próprias contas. O resultado do mês é o total de entradas menos os gastos registrados.

      Os dados ficam no navegador deste dispositivo. Abra sempre o mesmo arquivo no mesmo navegador e guarde um backup para recuperar seus lançamentos ou levá-los a outro dispositivo.
